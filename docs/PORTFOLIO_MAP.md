Pattern key: `ingest` reads messy exports as they come; `normalise` cleans values to one standard; `dedupe` merges or flags duplicates; `classify` puts each row in a named bucket; `score` explainable points-based score; `route` assigns an owner or next step; `review_queue` sends risky rows to a human with a reason; `crm_output` writes a CRM-ready import file, never writes to the CRM; `brief` writes a plain-English brief; `sql` uses SQL; `llm_optional` runs on rules; Claude only if a key is set.

## Descriptions

- **outbound-personalization-agent**: AI agent that generates personalized 3-touch outbound email sequences grounded in real trigger signals
- **account-signal-scoring-agent**: AI agent that scores accounts on fit + recency-weighted intent signals and routes hot accounts to AE with an auto-generated brief
- **lead-qualification-agent**: AI agent that scores inbound leads on fit + intent and routes them to PLG/SDR/AE
- **funnel-conversion-reporter**: Reports funnel conversion rates, biggest drop-off stage, and CAC from stage-count data
- **hubspot-meddpicc-long-cycle-setup**: (no GitHub description set)
- **event-lead-import-agent**: AI agent that cleans, dedupes and routes post-event lead lists (badge scans, attendees) into CRM-ready HubSpot/Salesforce import files, with a QA brief and sales handoff
- **closed-lost-reason-agent**: AI agent that audits closed-lost deals from HubSpot or Salesforce, finds the real loss reason behind 'Price' and 'Other', and builds a re-engage queue
- **utm-governance-agent**: AI agent that audits UTM tags from your link sheet or HubSpot/Salesforce export, maps messy variants to one taxonomy, shows where campaigns are split in reports, and checks links before launch
- **account-hierarchy-agent**: AI agent that matches enrichment parent companies to your Salesforce/HubSpot accounts, writes only safe parent links, sends loose matches to review, and flags company families split across reps
- **n8n-workflows-as-code**: Version your n8n workflows in GitHub: plain-English diffs, secret redaction, pinned-data removal and a CI audit. Runs with no API key.
- **hubspot-form-spam-triage-agent**: Score HubSpot form submissions for spam risk, quarantine the fakes and keep them out of workflows and reports, without deleting real leads. Runs with no API key.
- **python-for-gtm-basics**: Three small Python scripts for GTM: call the HubSpot API, transform the JSON, post a digest to Slack. Runs on sample data with no keys.
- **sdr-ae-handoff-brief-agent**: Agent that scores SDR-to-AE handoffs, sends weak ones back with questions, and writes first-call briefs. Runs with no API key.
- **inbound-lead-router-n8n-to-python**: A 23-node n8n inbound lead routing workflow rebuilt node for node as tested Python: junk filter, dedupe, CRM match, enrichment, scoring, round robin with OOO fallback, Slack alerts, error branch.
- **lifecycle-stage-audit-agent**: Audit HubSpot Lifecycle Stage and its history: custom values, stages that contradict deals, backward moves and workflows fighting over the field. Safe fix file plus review queue. Runs with no API key.
- **gtm-sql-revops-queries**: Seven RevOps SQL queries (funnel, stage velocity, lead-to-deal cohorts, pipeline coverage, attribution, data-quality audit, stalled deals) on a messy CRM-shaped SQLite dataset, with a Python runner, review queue and brief. No API key needed.
- **book-of-business-transfer-agent**: Plan the handoff when a rep leaves: rank their accounts, match each to the right rep (region, segment, fit, history, capacity), safe owner import, review queue, sequence re-enrol plan and briefs. No API key needed.
